# HyperModes

一个为HyperOS 打造的原生风格模式与自动化工具。

## 核心特性

### 1. 系统级集成，极致稳定
HyperModes 的核心逻辑运行在 `system_server` 进程中。App 本身仅作为一个配置编辑器，这意味着：
- **原生体验**：模式切换响应迅速，无任何第三方后台服务常驻。
- **进程无关**：即使 HyperModes App 被清理或卸载，已设置的自动化逻辑依然会在系统中准确执行。
- **超低功耗**：利用系统原生机制触发，不产生额外待机功耗。

### 2. 官方时钟深度接入
睡眠模式直接对接 HyperOS 官方“时钟”应用的就寝功能：
- **数据同步**：完美继承官方时钟的作息设置。
- **高稳定性**：利用系统内置的就寝触发机制，彻底解决第三方应用定时不准或被杀的问题。
- **无缝衔接**：支持官方闹钟响铃触发及手动关闭反馈。

### 3. 原生交互与高级功能
- **原生界面**：完全遵循 HyperOS / Miuix 设计语言，提供沉浸式的操作体验。
- **通知过滤**：支持自定义各个模式下的通知免打扰级别，精准控制重要信息的触达。
- **应用暂停**：进入特定模式后可自动暂停（置灰）选定应用，帮助您保持专注。
- **自定义状态栏图标**：
    - **语义映射**：为每个模式提供独特的单色矢量图标，完美适配系统状态栏。
    - **系统集成**：已在系统设置的“图标显示自定义”中集成“模式”开关，支持原生隐藏/显示控制。

## 安装与使用

1. 安装 APK。
2. 在 LSPosed 中激活模块，并勾选“系统框架”、“设置”和“时钟”。
3. 重启系统（或强制停止相关应用）以使 Hook 生效。
4. 打开 HyperModes App 开始创建您的个性化模式。
